# Framer Kit

A small collection of reusable Framer code components with responsive defaults, accessible controls and reduced-motion support.

## Components
- **Marquee** — looping content strip with pause-on-hover.
- **MagneticButton** — pointer-responsive button interaction.
- **BeforeAfter** — draggable image comparison slider.
- **CountUp** — animated number reveal.

Copy a component into Framer's Code Components, then expose the properties you need in the property controls. MIT licensed.
